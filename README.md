<h1>Validador de CPF</h1>
Projeto feito para estudar a validação de Cadastro de Pessoas Físicas (CPF) e todo o seu cálculo envolvido.
Projeto experimental apenas para fins acadêmicos.

&nbsp;

Pontos a melhorar futuramente:
- Tratar corretamente a entrada de dados;
- Invalidar determinados CPFs, como 111.111.111-11,e semelhantes;
- Permitir novas validações sem precisar reiniciar o programa.
